# 患者管理模块接口文档

## 1. 分页获取患者列表

### 接口说明
分页获取患者列表，支持基本的分页功能。

### URL
`GET /api/patient/list`

### 请求参数
| 参数名   | 类型   | 必填 | 描述     |
|---------|--------|------|----------|
| pageNum | Integer| 是   | 当前页码 |
| pageSize| Integer| 是   | 每页数量 |

### 请求示例
```
GET /api/patient/list?pageNum=1&pageSize=10
```

### 响应参数
| 参数名   | 类型   | 描述         |
|---------|--------|--------------|
| code    | Integer| 响应状态码   |
| msg     | String | 响应消息     |
| data    | Object | 响应数据     |
| ├─ total| Long   | 总记录数     |
| └─ list | Array  | 患者列表     |
|    ├─ id| String | 用户ID       |
|    ├─ name| String| 患者姓名     |
|    ├─ sex| String| 性别         |
|    ├─ phoneNum| String| 手机号   |
|    ├─ birth| Date| 出生日期     |
|    └─ IDNum| String| 身份证号  |

### 响应示例
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "total": 100,
    "list": [
      {
        "id": "U001",
        "name": "张三",
        "sex": "男",
        "phoneNum": "13800138000",
        "birth": "1990-01-01",
        "IDNum": "110101199001011234"
      }
    ]
  }
}
```

## 2. 查看患者详细信息

### 接口说明
根据患者ID查看患者的详细信息。

### URL
`GET /api/patient/detail/{id}`

### 请求参数
| 参数名 | 类型   | 必填 | 描述     |
|-------|--------|------|----------|
| id    | String | 是   | 患者ID   |

### 请求示例
```
GET /api/patient/detail/U001
```

### 响应参数
| 参数名   | 类型   | 描述         |
|---------|--------|--------------|
| code    | Integer| 响应状态码   |
| msg     | String | 响应消息     |
| data    | Object | 患者详细信息 |
| ├─ id   | String | 用户ID       |
| ├─ name | String | 患者姓名     |
| ├─ sex  | String | 性别         |
| ├─ phoneNum | String | 手机号   |
| ├─ email | String | 邮箱     |
| ├─ birth | Date | 出生日期     |
| ├─ IDNum | String | 身份证号  |
| ├─ medicalInsuranceID | String | 医保ID |
| └─ reimburseID | String | 报销类型ID |

### 响应示例
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "id": "U001",
    "name": "张三",
    "sex": "男",
    "phoneNum": "13800138000",
    "email": "zhangsan@example.com",
    "birth": "1990-01-01",
    "IDNum": "110101199001011234",
    "medicalInsuranceID": "MI001",
    "reimburseID": "R001"
  }
}
```

## 3. 修改患者详细信息

### 接口说明
修改患者的详细信息。

### URL
`PUT /api/patient/update/{id}`

### 请求参数
| 参数名   | 类型   | 必填 | 描述         |
|---------|--------|------|--------------|
| id      | String | 是   | 患者ID       |
| name    | String | 否   | 患者姓名     |
| sex     | String | 否   | 性别         |
| phoneNum| String | 否   | 手机号       |
| email   | String | 否   | 邮箱         |
| birth   | Date   | 否   | 出生日期     |
| IDNum   | String | 否   | 身份证号     |
| medicalInsuranceID | String | 否 | 医保ID |
| reimburseID | String | 否 | 报销类型ID |

### 请求示例
```json
PUT /api/patient/update/U001
{
  "name": "张三",
  "sex": "男",
  "phoneNum": "13800138000",
  "email": "zhangsan@example.com",
  "birth": "1990-01-01",
  "IDNum": "110101199001011234",
  "medicalInsuranceID": "MI001",
  "reimburseID": "R001"
}
```

### 响应参数
| 参数名 | 类型   | 描述       |
|-------|--------|------------|
| code  | Integer| 响应状态码 |
| msg   | String | 响应消息   |

### 响应示例
```json
{
  "code": 200,
  "msg": "操作成功"
}
```
