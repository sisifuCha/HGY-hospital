# 账户激活功能配置说明

## 功能概述

实现了患者账户的邮箱激活功能，分为两步：
1. **发送验证码**：前端提供身份证号、姓名、邮箱，后端发送6位验证码到邮箱
2. **验证激活**：前端提交验证码，验证成功后激活账户（patient.status = true）

## 数据库配置

### 1. 执行数据库迁移脚本

运行脚本添加status字段：
```sql
-- 位置：scripts/add_patient_status_column.sql
ALTER TABLE patient ADD COLUMN IF NOT EXISTS status BOOLEAN DEFAULT FALSE;
```

## 邮件配置

### 需要配置的信息

在 `PatientService/src/main/resources/application.properties` 中配置邮件信息：

```properties
# 邮件配置
spring.mail.host=smtp.example.com              # SMTP服务器地址
spring.mail.port=587                           # SMTP端口
spring.mail.username=your-email@example.com    # 发送邮箱
spring.mail.password=your-authorization-code   # 邮箱授权码
spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true
```

### 常用邮箱服务器配置

#### QQ邮箱
```properties
spring.mail.host=smtp.qq.com
spring.mail.port=587
spring.mail.username=你的QQ邮箱@qq.com
spring.mail.password=你的QQ邮箱授权码
```
授权码获取：QQ邮箱 → 设置 → 账户 → POP3/IMAP/SMTP服务 → 生成授权码

#### 163邮箱
```properties
spring.mail.host=smtp.163.com
spring.mail.port=465
spring.mail.username=你的163邮箱@163.com
spring.mail.password=你的163邮箱授权码
```
授权码获取：163邮箱 → 设置 → POP3/SMTP/IMAP → 开启并获取授权码

#### Gmail
```properties
spring.mail.host=smtp.gmail.com
spring.mail.port=587
spring.mail.username=your-email@gmail.com
spring.mail.password=your-app-password
```
授权码获取：Google账户 → 安全性 → 两步验证 → 应用专用密码

## API接口

### 1. 发送激活验证码
```
POST /user/activation/send-code
Content-Type: application/json

{
  "identificationId": "110101199001010011",
  "userName": "张三",
  "email": "zhangsan@example.com"
}
```

**响应示例**：
```json
{
  "code": 200,
  "message": "验证码已发送至您的邮箱，有效期为30分钟",
  "data": null
}
```

### 2. 验证激活码
```
POST /user/activation/verify
Content-Type: application/json

{
  "identificationId": "110101199001010011",
  "verificationCode": "123456"
}
```

**响应示例**：
```json
{
  "code": 200,
  "message": "账户激活成功！",
  "data": null
}
```

### 3. 查询激活状态
```
GET /user/activation/status?identificationId=110101199001010011
```

**响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": true
}
```

## 验证码机制

- **生成方式**：6位随机数字
- **存储方式**：Redis缓存
- **有效期**：30分钟
- **Key格式**：`activation:verification:{身份证号}`
- **验证失败**：不清除验证码，可重复尝试
- **验证成功**：自动清除验证码

## 安全特性

1. ✅ 身份证号格式验证（18位数字）
2. ✅ 邮箱格式验证
3. ✅ 验证码格式验证（6位数字）
4. ✅ 防止重复激活
5. ✅ 验证码过期自动失效
6. ✅ 日志记录（脱敏处理身份证号）

## 业务流程

```
用户注册
   ↓
注册成功（status=false）
   ↓
请求发送验证码（POST /send-code）
   ↓
系统验证身份证号、生成验证码、发送邮件
   ↓
用户收到邮件，输入验证码
   ↓
提交验证码（POST /verify）
   ↓
系统验证验证码
   ↓
验证成功 → 更新patient.status=true
   ↓
账户激活完成
```

## 注意事项

1. **必须先配置邮箱信息**，否则发送验证码会失败
2. **Redis必须运行**，验证码存储在Redis中
3. 建议在注册时将patient.status设置为false
4. 邮件发送失败时会自动清除已生成的验证码
5. 验证码30分钟内有效，过期需重新发送
